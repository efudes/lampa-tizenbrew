# Lampa for TizenBrew

This public fork adds only the metadata required to load the upstream
[`yumata/lampa`](https://github.com/yumata/lampa) web application in
TizenBrew. The application files are otherwise unchanged.

No third-party plugins, provider repositories, media sources, API keys, or
credentials are bundled.

## Install

1. Open TizenBrew's module manager.
2. Choose **Add GitHub Module**.
3. Enter `efudes/lampa-tizenbrew`.
4. Leave the input (for example, close the on-screen keyboard) so TizenBrew
   saves and refreshes the module list.
5. Launch the **Lampa** card.

TizenBrew loads GitHub modules through jsDelivr, so the repository must remain
public.
